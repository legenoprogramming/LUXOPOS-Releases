# Luxo POS Downloads

Official Windows and Android installers from LUX Solutions.
This repository contains distribution files and release notes only. Application source is maintained privately.

## Download

Open [Releases](https://github.com/legenoprogramming/LUXOPOS-Releases/releases) and select the published version:

- **Windows POS**: `Luxo-POS-Setup-1.0.0.exe`
- **Android POS**: `Luxo-POS-v1.0.0.apk`
- **Android Customer Display**: `Luxo-CDS-v1.0.0.apk`

Release notes include SHA-256 file checksums and installation guidance.
Finish active payments and save your work before updating. Do not uninstall the existing app or clear its data.

Windows builds are currently unsigned and may show a publisher warning. Android installers retain the existing release signing identity.

These downloads do not enable unattended native application updates. Server-delivered web updates and native installer updates are separate.
